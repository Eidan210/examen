# Plataforma de exámenes — Acme School

Aplicación web en JavaScript puro para **crear** exámenes y **resolverlos** con temporizador,
sobre una pantalla de acceso previa. Proyecto de formación construido sin frameworks.

`JavaScript (ES6+)` · `HTML5` · `CSS3`

---

## Qué hace

- **Login** — pantalla de acceso antes de entrar a la plataforma
- **Portal de creación** — el docente arma el examen y sus preguntas
- **Resolver examen** — el alumno responde con una cuenta atrás en pantalla

## Estructura

```
ProyectoJavaScript/Proyecto JavaScript/
├── login oc/                 → pantalla de acceso
├── PortalCreaciónExamen/     → creación de exámenes (app.js, styles.css)
└── ResolverExamen-contador/  → resolución con temporizador
```

## Cómo ejecutarlo

Abre el `index.html` de `login oc/` en el navegador, o usa la extensión **Live Server** de
VS Code sobre la carpeta del proyecto.

## Lo que demuestra

Manejo de estado en JavaScript sin framework, temporizador con `setInterval` y su limpieza, y
paso de datos entre vistas del navegador.
